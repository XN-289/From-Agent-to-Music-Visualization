# 使用与开发流程（Music Agent → Folia 管线）

## 1. 系统是什么

一句话闭环：在 Music Agent 里用自然语言聊一首歌，Agent 负责需求澄清、风格规划、写词与生成；歌曲完成后自动落盘到本地，并推送到本机 Folia Stage。随后在 Folia 中直接播放、切歌词可视化，并用桌面端内置能力导出横屏或竖屏视频。

## 2. 目录与职责

```text
music-agent/   Next.js + pi Agent + Suno 兼容 Provider
folia-major/   Folia 播放器（AGPL-3.0 上游副本）
docs/          管线说明、验收记录、执行计划
```

- `music-agent/`：聊天界面、Agent 规划与写词、生成任务轮询、SQLite 持久化、本地媒体落盘、Stage 推送。
- `folia-major/`：本地播放器、全屏歌词/视觉化、Stage API 接收端、Electron 视频导出。
- `docs/`：本文档与设计、计划、对抗性检验等记录。

## 3. 首次启动（按序）

### 1) Music Agent

```powershell
cd D:\从Agent到音乐可视化\music-agent
pnpm install
Copy-Item .env.example .env.local
pnpm db:push
pnpm dev
```

`.env.local` 中至少配置：

```env
# LLM（二选一）
DEEPSEEK_API_KEY=...
# 或中转站
LLM_BASE_URL=https://...
LLM_API_KEY=...

# 音乐生成：本机实际配置为 musicproxy（公司统一网关，默认）+ mock（免费演示）
SUNO_PROVIDER=musicproxy
MUSIC_PROXY_BASE_URL=http://127.0.0.1:8800
MUSIC_PROXY_API_KEY=...
MUSIC_PROXY_DEFAULT_PROVIDER=suno_openaihk
MUSIC_PROXY_MODEL=auto

# Folia Stage
FOLIA_STAGE_BASE_URL=http://127.0.0.1:<Folia 显示端口>
FOLIA_STAGE_TOKEN=<Folia 显示 token>
FOLIA_WEB_URL=http://127.0.0.1:3001
```

### 2) Folia

```powershell
cd D:\从Agent到音乐可视化\folia-major
npm install
npm run dev:electron
```

### 3) Stage 打通

1. Folia 桌面端进入设置，开启 `Stage Mode`，来源选择 `Stage API`。
2. 记下界面显示的 Stage 端口与 Bearer token。
3. 回填到 `music-agent/.env.local` 的 `FOLIA_STAGE_BASE_URL` 与 `FOLIA_STAGE_TOKEN`。
4. 重启 `music-agent` 的 `pnpm dev`。

### 4) 验证

```powershell
curl -s http://127.0.0.1:<端口>/stage/health
```

预期返回中 `enabled`、`modeEnabled` 为 true，`source` 为 `stage-api`。

### 5) 免费离线验收（可选）

不启动 Folia 桌面端也可以先跑通生成、落盘与 Stage 推送。以下方式只用于本地验收，不进入日常使用：

```powershell
# 终端 A：启动临时 Stage 接收端，并把新 token 写回 music-agent/.env.local
cd D:\从Agent到音乐可视化\folia-major
node test/manual/stage-api-dev.cjs --sync-env

# 终端 B：用独立端口/数据库启动 mock Music Agent
cd D:\从Agent到音乐可视化\music-agent
$env:SUNO_PROVIDER='mock'
$env:DB_PATH='D:\从Agent到音乐可视化\music-agent\data\music-agent-mock.db'
$env:MEDIA_OUTPUT_DIR='data/media-mock'
$env:FOLIA_STAGE_BASE_URL='http://127.0.0.1:32107'
pnpm db:push
pnpm dev --port 3002
```

然后直接调用开发端点，跳过 LLM 与浏览器：

```powershell
$body = @{
  title = '日文 J-POP 情歌'
  lyrics = "夏の夜の花火が咲く`n// 夏夜的花火绽放`n君と見上げたあの空`n// 和你一起仰望的那片天空"
  styleTags = @('jpop')
} | ConvertTo-Json
$r = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:3002/api/dev/generate' -ContentType 'application/json; charset=utf-8' -Body $body
$r | ConvertTo-Json
```

轮询 `GET /api/jobs/<jobId>` 直到 `status=success`，再检查 `data/media-mock/<songId>/`。关闭 Stage 接收端后生成应仍成功，手动 `POST /api/songs/<songId>/push-folia` 应返回 503；重启 Stage 后重推应返回 200。

## 4. 日常使用流程

1. 在 Music Agent 新建对话，描述想要的歌曲。Agent 会先确认主题、场景、方向，再写词并生成。
2. 日文或非中文主语言歌曲，写词阶段会在每行歌词下方输出 `//` 中文翻译行。
3. 生成完成后，Music Agent 自动把 `audio / lyrics.lrc / lyrics.t.lrc / cover.<png|jpg|webp> / meta.json` 落盘到 `music-agent/data/media/<songId>/`；封面优先采用公司网关返回的生成封面，失败再回退本地渐变封面。
4. 若 Folia Stage 已开启，音乐会自动推送到 Folia 并开始播放。
5. 在 Folia 中查看曲库、全屏歌词或可视化，并使用视频导出能力生成横屏/竖屏 MP4。
6. 如果 Folia 当时没有开启，详情页 `push-folia` 按钮可手动重推。

## 5. 双语与翻译链路

1. Harness 写词规范要求非中文主语言歌曲逐行写 `//` 中文翻译。
2. 提交给 Suno 前，`stripTranslationLines` 会剥离所有 `//` 行，避免翻译被唱出来。
3. 生成完成时，`buildTranslationLines` 把翻译行映射到主歌词时间轴，生成 `lyrics.t.lrc`。
4. 推送到 Folia 前，`embedSongMetadata` 会把主歌词与翻译写入 MP3 的 USLT 帧（`eng` 主歌词 + `chi` 翻译）。
5. Folia 从上传音频提取 `translationLyrics`，渲染为原文下方的淡色副字幕。

检查真实 MP3 内嵌歌词帧：

```powershell
cd D:\从Agent到音乐可视化\music-agent
node scripts/check-metadata.mjs "data/media/<songId>/audio-01-*.mp3"
```

## 6. 关键环境变量表

| 变量 | 作用 |
|---|---|
| `LLM_PROVIDER` / `DEEPSEEK_API_KEY` | 直连 DeepSeek |
| `LLM_BASE_URL` / `LLM_API_KEY` | OpenAI 兼容中转站；设置后优先 |
| `SUNO_PROVIDER` | `musicproxy`（公司网关，默认）、`mock`（免费演示）、`sunoapi`（第三方 API） |
| `SUNO_API_KEY` | `sunoapi` 后端密钥；公司网关无需此项 |
| `MUSIC_PROXY_BASE_URL` / `MUSIC_PROXY_API_KEY` | 公司统一音乐网关 |
| `FOLIA_STAGE_BASE_URL` / `FOLIA_STAGE_TOKEN` | 本机 Folia Stage API 地址与令牌 |
| `FOLIA_WEB_URL` | 推送成功后给详情页展示的 Folia 地址 |
| `DB_PATH` | SQLite 文件路径 |

## 7. 常见问题

- **Folia 推送不成功**：Stage Mode 未启用、来源不是 `Stage API`、端口与 token 未同步，或 `music-agent` 未重启读取新 env。
- **副字幕不显示**：mock 生成的是 WAV，没有 ID3 帧；真实 MP3 若仍不显示，先运行 `scripts/check-metadata.mjs` 确认 USLT 帧已写入。
- **歌词对不上**：真实 Suno 对齐行数与翻译行数不一致。当前 P0 用主歌词行序共轴，复杂副歌重复段可能出现错位，需要真实对齐数据后复验。
- **端口占用**：`3000` 被其他本地项目占用时，可在 `pnpm dev --port 3002` 启动 Music Agent，并同步调整 `MUSIC_AGENT_ORIGIN`。

验收清单：

- [x] 中文 mock 歌生成成功，`data/media/<songId>/` 有 `audio-*.wav`、`lyrics.lrc`、`cover.png`，无 `lyrics.t.lrc`。
- [x] 日文 mock 歌生成成功，有 `lyrics.t.lrc`，`meta.json` 含 `tLrc`。
- [x] Stage 自动推送与断 Folia 后手动重推兜底可用（桌面端自动播放仍需目视验收）。
- [ ] 真实公司网关（musicproxy）日文歌在 Folia 中显示原文日文 + 中文副字幕。
- [ ] 横屏 1920x1080 与竖屏 1080x1920 视频可导出。
