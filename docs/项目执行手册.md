## 一、项目是什么（一句话）

**本地闭环：打开对话框 → 与「专业 AI 音乐制作人」Agent 聊天深挖需求 → Suno 真实生成歌曲 → 生成完自动推送到 Folia 可视化播放器并自动播放（原文+中文翻译副字幕+封面）→ 长时间全屏观看 → 导出横屏/竖屏纯净视频发到视频网站。**

用户原话核心：用户是音乐小白；Agent 负责深挖「想要什么表现形式、表达什么情感」；最终目的是**表达欲**——把自己做的歌的视觉效果发到视频网站给大家看。

## 四、设计（已批准，冻结）

完整设计：`docs/superpowers/specs/2026-08-21-music-agent-folia-design.md`

核心方案（全部基于代码级侦察验证）：

1. **翻译副字幕链路（P0）**：harness 写词规范让 Agent 在日文歌每行下写 `// 中文翻译` 行 → 提交 Suno 前剥离（`stripTranslationLines`）→ 落盘 `lyrics.t.lrc`（与主歌词共轴）→ 推送前用 node-id3 把主歌词+翻译写入 MP3 的 **USLT 双帧**（原文 `language='eng'`；翻译 `language='chi'` + descriptor `translation`，与 Folia `metadataParser.worker.ts` / `stageApi.cjs` 的识别合同精确对齐）→ Folia 端 3 处最小透传（`translationLyrics` 字段带出 → 渲染端 `tLrcContent` 显示副字幕）。
2. **封面**：本地渐变 PNG（@resvg/resvg-js，系统字体中文）落盘 `cover.png`，推送走 Stage 原生 `coverFile` 字段 + 嵌入 MP3 APIC 双保险。
3. **自动推送**：已存在（`queueAutoDelivery`，jobs 完成时触发）；进程内去重，失败静默、按钮兜底。
4. **零开发项**：自动播放、横竖屏导出、封面推送通道——全部 Folia 已内置。
5. **mock 限制**：mock 产出 **WAV**（无 ID3），翻译副字幕只能在真实 MP3（sunoapi）上验收；mock 阶段只验 t.lrc 落盘与推送不炸。
