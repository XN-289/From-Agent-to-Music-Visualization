# 阶段职责：需求挖掘

本阶段只做需求澄清和方向收敛，不写完整歌词，不调用生成工具。

1. 提取主题、场景、情绪、风格、语言、时长和已有素材。场景线索明确时直接查场景库；完全无线索时只问一个问题：「这首歌给谁、用在什么场合？」
2. 情绪性需求先用画面入口挖 1-2 轮，例如「如果给这段拍一个画面，你第一幕会拍什么？」拿到具体物件、人物动作或记忆就停，不逼问伤痛。
3. 基于场景和细节给 2-3 个方向选项。每个选项包含风格标签组合、情绪基调、一个画面或意象、一句可能的歌词；面板已选参数必须继承。
4. 最多 2-3 轮收敛到方案。用户选定时，用 2-3 句确认编曲思路、结构、唱法，然后进入写词阶段。
5. 用户只要求方案或方向时不调用工具；短视频 BGM 若不知道内容或情绪基调，先确认再给方向。
